# CS406 Professional IT Practices
# Documentation Site

A personal documentation site created as part
of the CS406 Professional Practices in IT unit.
EduQual Level 5 Diploma in Computer Science.

## Purpose

This repository documents key professional IT
practices for new starters in an IT environment,
covering version control workflows, accessibility
standards, and data protection basics.

## Pages

- index.html — Home and navigation
- version-control.html — Git workflow guide
  for new developers
- accessibility.html — WCAG 2.1 overview
  and practical checklist
- data-protection.html — UK GDPR basics
  for IT professionals

## Audience

New starters at an IT firm who need a quick
reference guide to professional practices.
No prior technical knowledge assumed.

## How to Use

1. Clone the repository:
   git clone https://github.com/ahmedshah03/
   cs406-documentation-site.git
2. Open index.html in any modern browser
3. No build step or dependencies required

## Accessibility

All pages meet WCAG 2.1 Level AA standards:
- Semantic HTML5 elements throughout
- All images have descriptive alt attributes
- Colour contrast ratio exceeds 4.5:1
- All forms have explicit label elements

## Version Control Approach

This repository follows a feature branch
workflow:
- Each page developed on its own branch
- Descriptive commit messages on every commit
- Main branch contains only reviewed code
