WCAG 2.1 Accessibility Guide

This guide introduces the key Web Content Accessibility Guidelines for IT professionals building digital products.

What is WCAG 2.1?

WCAG 2.1 is the international standard for web accessibility published by the W3C. It sets the bar for making web content accessible to people with disabilities.

Conformance Levels

  • Level A — minimum standard
  • Level AA — required by UK law for public sector sites
  • Level AAA — highest standard

Quick Checklist for Developers

  • All images have descriptive alt attributes
  • All form inputs have explicit label elements
  • Colour contrast ratio is at least 4.5:1 for normal text
  • Error messages are not communicated by colour alone
  • All content is reachable by keyboard
  • Skip navigation link provided on every page
  • Page language is declared using the lang attribute on the html element
